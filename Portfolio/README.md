# 💼 Portfolio Website — CodeAlpha Task 3

A personal portfolio website showcasing my skills, experience, and background, built with a dark navy theme using HTML and CSS.

## ✨ Features

- Dark navy themed, modern UI
- Sections for introduction, skills, and teaching experience
- Skills highlighted: HTML, CSS, jQuery, C Programming, Python, MS Office, Adobe Photoshop, Adobe Illustrator
- Teaching experience section (Computer Instructor at Career Boosting Learning Academy, since 2023)
- Fully responsive design for desktop and mobile
- Built with pure CSS — no external frameworks — for complete control over styling

## 🛠️ Built With

- HTML5
- CSS3 (custom dark theme, responsive layout)

## 📂 File Structure

```
Portfolio/
└── index.html   (includes embedded styling)
```

## ▶️ How to Run

1. Clone or download this folder
2. Open `index.html` in any web browser

## 📌 Key Learning

Designing a cohesive dark theme from scratch — balancing contrast, readability, and a professional look — while structuring content to clearly present skills and teaching experience to potential recruiters or clients.

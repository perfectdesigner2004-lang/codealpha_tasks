# Image Gallery — CodeAlpha Task 2

A responsive, category-based image gallery web app built with HTML, CSS, and JavaScript.

## Features

- Multiple image categories with filter buttons
- Smooth category filtering (view images by category or view all)
- Hover animations on gallery images
- Lightbox view — click any image to see it in a larger, focused view
- Fully responsive layout for mobile and desktop

## Built With

- HTML5
- CSS3 (grid layout, hover transitions)
- Vanilla JavaScript (filtering and lightbox logic)

## How to Run

1. Clone or download this folder
2. Open `index.html` in any web browser
